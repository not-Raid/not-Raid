## About Me

I build embedded systems, custom PCBs, and real-time hardware applications. Moving seamlessly from high-level code to hardware level—bridging the gap between software logic and microcontrollers.

- **Primary Microcontroller:** ESP32 (DevKit v1)
- **EDA & Layout:** EasyEDA Pro
