## What I Do

I build custom hardware, design breakout PCBs, and write code to link physical devices with real-time software streams. 

- **Primary Focus:** Custom PCB layouts & hardware prototyping
- **Core Languages:** C++ & Python
- **Interests:** Real-time data streaming, wireless telemetry, and interactive hardware
